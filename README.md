# Taawon

Site vitrine pour **Taawon**, une association qui valorise l'artisanat marocain et ses coopératives.
Les contenus sont des données de démonstration, non vérifiées.

## Pages

| Fichier | Contenu |
|---|---|
| `index.html` | Accueil |
| `cooperatives.html` | Annuaire des coopératives par région |
| `cooperative.html` | Fiche détaillée d'une coopérative (exemple : Tazrout) |
| `partenaire.html` | Formulaire pour rejoindre le réseau |
| `a-propos.html` | À propos |

## Technologies

- HTML
- [Tailwind CSS](https://tailwindcss.com/) v4
- Polices Google Fonts : Cormorant Garamond, Inter, Google Sans

## Structure

```
.
├── assets/
│   ├── icons/       # logo et icônes
│   └── images/      # photos des coopératives
├── src/style.css    # CSS source (Tailwind + styles perso)
├── dist/output.css  # CSS généré
├── *.html           # pages du site
└── package.json
```
